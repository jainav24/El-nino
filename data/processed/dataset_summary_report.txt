=== Target Variables for Survival Analysis ===
1. duration (`time_to_claim`): The number of days from the start of the crop season until a claim is filed. If no claim is filed, it is the total duration of the crop season.
2. event (`claim_occurred`): Binary indicator (1 if a claim was filed, 0 if the policy ended without a claim, representing right-censored data).
   - Construction: We compute a hazard rate combining drought severity, flood severity, poor irrigation, and temperature deviations. Using this hazard rate, an exponential distribution simulates 'time_to_failure'. If this time is less than the crop season's maximum duration, an event (claim) occurs.

=== Feature Engineering Context ===
Variables like `rainfall_deviation`, `drought_index`, and `weather_anomaly_score` are included to establish ground-truth causal relationships in this synthetic environment. In the ML pipeline, these will be treated as derived features from the raw telemetry (rainfall, temperature).

=== Synthetic Data Limitations (For Academic Disclosure) ===
To ensure academic integrity, the following limitations must be disclosed in the project report:
1. Synthetic Causality: The relationships between El Niño, weather anomalies, and crop failure are heuristically programmed via a defined hazard function, rather than empirically derived from true historical actuarial loss tables.
2. Lack of Micro-climates: Weather features are modeled at a generalized distribution level without complex spatial auto-correlation (e.g., adjacent farms experiencing identical local floods).
3. Temporal Independence: Each row acts as an independent policy without longitudinal farmer history, missing the true year-over-year temporal dynamics of agricultural risk.
