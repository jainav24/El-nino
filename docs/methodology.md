# Project Methodology

The objective of this project is to create an AI-driven risk assessment model tailored for the agricultural insurance sector, specifically analyzing the impacts of El Niño weather anomalies.

## Approach
1. **Data Aggregation**: Centralizing policy lifetimes, agricultural metrics, and ENSO climate indicators.
2. **Feature Engineering**: Transforming static records into time-to-event rows.
3. **Modeling**: Applying Survival Analysis instead of standard regression.
4. **Platform Delivery**: A decoupled React/FastAPI architecture to serve predictions and dynamic analytics to stakeholders.
