# System Architecture

## Overview
The platform utilizes a decoupled, modern web stack.

### Frontend
- **Framework**: React with Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Visualization**: Recharts

### Backend
- **Framework**: FastAPI (Python)
- **Data ORM**: SQLAlchemy
- **Machine Learning**: Lifelines (Cox Proportional Hazards)

### Infrastructure
- **Database**: PostgreSQL (Production) / SQLite (Dev)
- **Containerization**: Docker
